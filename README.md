# The New Rule

**An open-source, LLM-powered government simulator — a text-based game where you rule a fictional country for a 4-year presidential term, and an AI writes the consequences of everything you do.**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
![TypeScript](https://img.shields.io/badge/TypeScript-100%25-blue)
![DeepSeek](https://img.shields.io/badge/LLM-DeepSeek%20(OpenAI--compatible)-purple)

Type any action in free text — pass a law, declare war, nationalize the memes — and the game reacts: the economy shifts, four social strata change their mood, newspapers publish issues, story arcs unfold. Every run is unique, because the narrative is generated by an LLM while a deterministic engine keeps the simulation honest.

## Features

- **Free-text actions** — no menus of pre-approved decisions. You type what you do; the game figures out what it means (law, decree, statement, war, or "other").
- **192 weeks in office** — a full 4-year term, ticking week by week, with optional 2–13 week time skips.
- **A living country** — 11 stats (economy, poverty, inflation, freedom, corruption, stability, power concentration, education, technology, war mood…) plus derived indicators: housing bubble, homelessness, population with emigration.
- **Four social strata** — elites, military, workers, and youth, each with its own mood ranging from *love* to *impeachment*. Freeze a layer, and it stops reacting to anything but a costly gesture of reconciliation.
- **Hard crisis arcs** — military coup, protests escalating into civil war, oligarchs, a neighbor's invasion, and your own offensive wars (the public checks your justification).
- **Dynamic LLM-generated events & custom story arcs** — the AI creates plotlines from your actions and keeps them consistent through a chronicle and a recurring character registry.
- **Two game modes** — *Realism* (consequences as in the real world; absurdity is penalized) and *Creativism* (the world plays along; absurdity earns bonus points).
- **Multiple endings** — peaceful handover, re-election, life-long rule, overthrow, or total collapse, each with its own score multiplier and an AI-written epilogue set 10 years later.
- **Three languages** — full UI, prompts and news in English, Russian and Ukrainian.
- **Playable for free** — a built-in `MockLLM` stub lets you run the entire game with no API key and zero cost.
- **Saves & autosaves** — drop a run and pick it up later.

## How it works

The project is a deliberate hybrid: **the LLM never touches game state directly.**

1. Your action is parsed by an LLM into structured JSON: numeric deltas, mood shifts, treasury changes, ideology tags, absurdity rating.
2. A strict **Zod validator** clamps everything to the balance caps — no runaway hallucinated numbers.
3. A **deterministic engine** applies the validated effects, ticks the simulation, fires crisis triggers and derives secondary indicators.
4. The LLM then *narrates* the results: newspaper issues, event flavor, dynamic story arcs — all consistent with the machine-generated chronicle.

All game balance lives in a single file: [`engine/config.ts`](engine/config.ts).

## Quickstart

Requires Node.js 18+.

```bash
git clone https://github.com/SlpPan4/the-new-rule.git
cd the-new-rule
npm install
cp .env.example .env
```

**Free mode (no API key):** set `USE_MOCK_LLM=true` in `.env` (it's the default) and run:

```bash
npm run dev
```

**Full AI mode:** get a [DeepSeek API key](https://platform.deepseek.com/) (it's cheap — the game caches actions and keeps prompts compact), fill in `.env`:

```env
DEEPSEEK_API_KEY=sk-...
USE_MOCK_LLM=false
```

Any OpenAI-compatible provider works too — just change `DEEPSEEK_BASE_URL` and `DEEPSEEK_MODEL`.

## Development

```bash
npm run test        # vitest — engine, validator, arcs, saves, i18n
npm run typecheck   # strict TypeScript
```

The simulation core (`engine/`, `llm/`) is covered by unit tests and knows nothing about language — all localization lives in `i18n.ts`. See [`AGENTS.md`](AGENTS.md) for the full architecture spec (useful if you want a coding agent to contribute).

## По-русски

**The New Rule** — текстовый симулятор государства на LLM: вы — президент вымышленной страны, срок — 4 года (192 недели), действия вводятся свободным текстом, а нейросеть (DeepSeek) пишет последствия, новости и сюжетные арки. Движок детерминированный: LLM только предлагает числа, валидатор Zod их обрезает по балансу.

- Два режима: **реализм** (последствия как в жизни) и **креативизм** (мир подыгрывает, абсурд — в плюс).
- Кризисные арки: переворот, протесты → гражданская война, олигархи, вторжение соседа, свои войны.
- Концовки от мирной передачи власти до краха страны, с эпилогом «10 лет спустя».
- Работает **бесплатно без API-ключа** в режиме заглушки (`USE_MOCK_LLM=true`).
- Интерфейс на русском, украинском и английском.

Запуск: `npm install` → `cp .env.example .env` → `npm run dev`. Весь баланс — в `engine/config.ts`.
